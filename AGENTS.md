# development

- static browser game with vendored three.js r160 in `vendor/three/`; no runtime build step.
- run `python3 devserver.py` from this folder for the no-cache server on port 5179.
- check changed javascript with `node --check <file>` and run `git diff --check`.
- verify in a browser. local-only `window.__rawah` hooks (`begin`, `goto`, `teleport`, `setHour`, `look`, `press`, `hold`, `step`, `map`) drive deterministic checks when pointer lock is unavailable; `step(n)` only renders the last frame. keep the hooks disabled on public hosts.
- world data in `data/` is generated by `tools/bake_world.py` from real sources (USGS lidar, Sentinel-2, Overture/OpenStreetMap); edit the script and re-bake rather than hand-editing `world.json` or the binaries. downloads and expensive rasters cache in `tools/.cache/`.
- `World.height()` is lidar (`baseHeight`, quad split along the (c, r)-(c+1, r+1) diagonal) plus micro-relief from `src/detail.js`; the CDLOD vertex shader computes the same thing. keep the JS and GLSL halves of `detail.js` in lock-step (same hashing, octaves, offsets, weights) or the hiker will float or sink.
- `World.cover()` turns the baked Sentinel-2 land cover (live conifer, burned, aspen, rock) plus terrain into the weights flora uses; keep tree placement driven by it so trees match the satellite colour underneath.
- names come only from OpenStreetMap data; do not invent names for unnamed lakes or features.
- all sound is synthesized in `src/audio.js`; no audio files.
- trees are generated at startup in `src/trees.js` (painted atlas, card meshes, impostor bake); flora placement stays in `src/flora.js`.
- camera feel lives in `src/camera.js` and is driven by `Hiker.phase` (PI per footstep); keep footstep audio and head bob on that same phase. `V` toggles first/third person; `src/avatar.js` is a placeholder meant to be replaced by a rigged model.

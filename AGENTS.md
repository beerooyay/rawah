# development

- static browser game with vendored three.js r160 in `vendor/three/`; no runtime build step.
- run `python3 devserver.py` from this folder for the no-cache server on port 5179.
- check changed javascript with `node --check <file>` and run `git diff --check`.
- verify in a browser. local-only `window.__rawah` hooks (`begin`, `goto`, `teleport`, `setHour`, `look`, `press`, `hold`, `step`, `map`) drive deterministic checks when pointer lock is unavailable; `step(n)` only renders the last frame. keep the hooks disabled on public hosts.
- world data in `data/` is generated by `tools/bake_world.py`; edit the script and re-bake rather than hand-editing `world.json` or the `.bin` heightfields.
- `World.height()` must match the terrain mesh triangulation (quad split along the (c, r)-(c+1, r+1) diagonal); collision, trails and props all sample it.
- `World.cover()` is the single source of land cover for the colour map and tree placement; change ecology there so near trees and far canopy tint stay consistent.
- only name lakes and peaks we are sure of; everything else stays labelled by elevation.
- all sound is synthesized in `src/audio.js`; no audio files.
